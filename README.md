প্রশ্ন ১

JavaScript কী?
JavaScript (JS) হলো একটি Programming Language।এটা দিয়ে আমরা ওয়েব পেইজেকে ইন্টারেকটিভ করতে পারি।যেমন বাটনের কাজ,ফমর ভেলিটেশন ইত্যাদী।
প্রশ্ন ২

Programming Language কী?

Programming Language হলো এমন একটি ভাষা যার মাধ্যমে আমরা কম্পিউটারকে কোন কাজ করার নির্দেশ দিতে পারি । বা কম্পিউটারের সাথে কথা বলার ভাষাকে প্রোগ্রামিং Language বলে।
প্রশ্ন ৩

নিচের কোনটি JavaScript-এর প্রধান কাজ?

C. ওয়েব পেজে Interaction ও Functionality যোগ করা

প্রশ্ন ৪

HTML, CSS এবং JavaScript-এর কাজ মিলিয়ে লেখো।

উদাহরণ:

HTML → ওয়েব পেইজের স্টাকচাকর তৈরী করতে লাগে।
CSS → ওয়েব পেইজকে বিভিন্ন স্টাইল করেত বা ডিজাইন করতে লাগে।
JavaScript → ওয়েব পেইজকে কার্যকর বা ইন্টরেকটিভ করতে লাগে বা বিভিন্ন  ফাংশন যোগ করতে ব্যবহার হয়।

👀 Code Reading

নিচের HTML কোডটি দেখো।

<!DOCTYPE html>
<html>
<head>
  <title>My First JS</title>
</head>
<body>

  <h1>Hello JavaScript</h1>

  <script>
    console.log("Welcome to JavaScript");
  </script>

</body>
</html>
প্রশ্ন
<script> Tag-এর কাজ কী? ওয়েব পেইজে JavaScript যোগ করেত বা অন্য JavaScript ফাইলকে html file এর সাথে কানেক্ট করতে ব্যবহার হয়।
console.log("Welcome to JavaScript"); কী করবে? এ কোডটিকে ব্রাউজারের কনসলে প্রিন্ট করবে।

💻 Coding Challenge

একটি নতুন index.html ফাইল তৈরি করে নিচের কাজগুলো করো।

একটি <h1> লিখবে:
Welcome to JavaScript
<script> Tag-এর ভিতরে লিখবে:
console.log("Hello World");
ব্রাউজারের Console-এ Output দেখবে।

🏆 Master Test

Hint ছাড়া নিজে একটি HTML File লেখো যেখানে—
